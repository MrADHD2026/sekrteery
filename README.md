# سكرتيري

سكرتيرك الشخصي: يجمع المواعيد والمهام والإيفنتات بتنبيه قوي بشاشة كاملة، والمصروفات والدخل بالتسجيل الصوتي أو اليدوي، مع داشبورد لكل قسم.

## محتويات المشروع

| المجلد | وش فيه |
|---|---|
| `www/` | الواجهة كاملة (نفسها للجوال والتابلت والكمبيوتر) |
| `www/js/parser.js` | محلل الكلام العربي: يفهم المبالغ والعملات والبنود والتواريخ والأوقات ودرجة الأهمية |
| `android/` | تطبيق أندرويد: المنبه بالشاشة الكاملة، والتعرف على الصوت، والمزامنة في الخلفية |
| `.github/workflows/build-apk.yml` | يبني ملف APK تلقائياً مع كل تحديث |
| `firestore.rules` | قواعد حماية البيانات في Firebase |

## ١. تثبيت التطبيق على الجوال والتابلت (سامسونج)

1. افتح صفحة **Releases** في مستودع GitHub من الجوال، ونزّل `sekrteery.apk`.
2. افتح الملف. لو طلع لك تنبيه "تثبيت تطبيقات غير معروفة"، اسمح للمتصفح أو "ملفاتي" بالتثبيت.
3. افتح سكرتيري ← الإعدادات ← **صلاحيات التنبيه القوي**، وفعّل الخمس صلاحيات كلها.
4. إعدادات مهمة لسامسونج:
   - الإعدادات ← البطارية ← حدود استخدام الخلفية ← **التطبيقات التي لا تدخل في وضع السكون أبداً** ← أضف سكرتيري.
   - الإعدادات ← التطبيقات ← سكرتيري ← البطارية ← **غير مقيّد**.
5. من الإعدادات ← **جرّب التنبيه** ← "قوي ومتكرر"، واقفل الشاشة. بعد ١٠ ثواني لازم تطلع لك الشاشة الحمراء.

## ٢. المزامنة بين كل أجهزتك (Firebase، مجاني)

بدون هذي الخطوة، كل جهاز يحفظ بياناته لحاله.

1. ادخل [console.firebase.google.com](https://console.firebase.google.com) بحساب جيميل حقك ← **Add project** ← سمّه `sekrteery`.
2. من **Build ← Authentication** ← Get started ← فعّل **Email/Password**.
3. من **Build ← Firestore Database** ← Create database ← اختر منطقة قريبة (مثلاً `europe-west`، أو `me-central2` لو متوفرة) ← Production mode.
4. في تبويب **Rules** الصق محتوى ملف `firestore.rules` واضغط Publish.
5. من ⚙️ **Project settings ← Your apps** ← اضغط أيقونة الويب `</>` ← سجّل التطبيق ← انسخ `firebaseConfig`.
6. في سكرتيري ← الإعدادات ← المزامنة: الصق الإعدادات ← حفظ وتفعيل ← **حساب جديد** بإيميلك وكلمة مرور.
7. في باقي الأجهزة: الصق نفس الإعدادات، وسجّل **دخول** بنفس الإيميل.

> عشان ما تحتاج تلصق الإعدادات في كل جهاز: حطها في `www/js/config.js` مرة وحدة، وارفع التحديث.

## ٣. على الكمبيوتر (HP / Lenovo)

ارفع مجلد `www` على أي استضافة فيها HTTPS، مثل Bluehost أو Firebase Hosting أو GitHub Pages. بعدها افتح الرابط في كروم واضغط أيقونة **تثبيت** في شريط العنوان، ويصير عندك تطبيق على سطح المكتب.

على الكمبيوتر، التنبيهات تطلع طالما الصفحة مفتوحة. التنبيه القوي الحقيقي يشتغل من الجوال.

## درجات الأهمية

| الأهمية | التنبيه |
|---|---|
| عادي | إشعار عادي فيه أزرار "تم" و"أجّل" |
| مهم | شاشة كاملة بصوت المنبه، وترجع مرة ثانية بعد ١٠ دقائق لو تجاهلتها |
| عاجل | شاشة كاملة تتكرر كل ٥ دقائق (٥ مرات) لين تختار |

## بناء ملف APK

أي تعديل ينرفع على فرع `main` يبني APK جديد تلقائياً، وينزل في Releases. مفتاح التوقيع محفوظ في أسرار المستودع (`SK_KEYSTORE_B64` و `SK_KEYSTORE_PASS`)، ولازم يبقى نفسه عشان التحديثات تنزل فوق النسخة القديمة بدون ما تنحذف بياناتك.
